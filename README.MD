# Project Myra Invest

## AI-Powered Daily Stock Recommendation Platform

Project Myra Invest is a Scala + Apache Spark + Databricks application that generates five daily stock recommendations for the Indian stock market using market prices, news, fundamentals, technical indicators, and AI-generated reasoning.

### Vision

Every morning, Myra Invest answers one question:

> **"Which 5 stocks are worth researching today, and why?"**

### Technology Stack

* Scala
* Apache Spark
* Databricks
* Delta Lake
* GitHub
* OpenAI (AI summaries in Version 1)

### Version 1 Features

* Daily stock price ingestion.
* News ingestion.
* Bronze / Silver / Gold Delta pipelines.
* Recommendation scoring engine.
* AI-generated investment brief.
* Daily dashboard.
